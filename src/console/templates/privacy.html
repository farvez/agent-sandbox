Privacy Policy

Last updated {{ updated }}.

Airlock is a hosted service for running code from AI agents in isolated sandboxes, operated by Farvez Anzam ("we"). This page explains what the hosted service at {{ base_url }} stores, why, and for how long. The source code is public, so you can check every point below.

What we store

DataWhyKept for
Your GitHub account ID, username, display name and avatar URL, when you sign in To identify your account and show who you are in the console Until your account is removed
Invite requests: what you'd use Airlock for, and the contact you choose to give To review the request and tell you when you're in Until the request is approved or dismissed
API keys: an ID and the name you chose. The key itself is stored only as a one-way hash. To check requests are yours Until you revoke the key; revoked keys are kept as records
Activity: each command you run, as typed, with time, session, which key or console user ran it, exit code and duration. Never the command's output. So you (and we, for abuse and security) can see what ran 90 days
Internet connection log: each outbound connection your sandboxes attempt (host, allowed or refused, bytes) To enforce and show what your sandboxes reached 30 days
Monthly usage totals: sessions, commands and sandbox time To show your usage and set fair limits Until you ask us to delete them
If you connect GitHub for private repositories: the installation ID and the account names it covers To import the repositories you chose. We read a repository's contents only when you import it, with a token that lasts an hour, covers that one repository and is never stored. Until you disconnect
Files in your workspaces So your code persists between commands Deleted when the session closes (when you close it, or after 30 minutes without use)
Server request logs, including IP addresses To operate the service and investigate abuse 14 days

We don't store your GitHub access token: sign-in asks GitHub only for your public profile (read:user), and the token is discarded right after. Commands are stored as typed, so don't put passwords or keys in command lines; write them to a file instead.

Cookies

Only cookies the console needs to work: your sign-in (7 days), a sign-in check while you're on GitHub (10 minutes), one-time notices (2 minutes), and your verified GitHub identity while you request an invite (30 minutes). No analytics, advertising or tracking cookies.

Who else handles it

  • Amazon Web Services hosts the service and its databases in the United States (us-east-1).
  • GitHub handles sign-in and, if you connect it, private repository access.
  • When you request an invite, its details are emailed to the operator through Amazon SNS.

We don't sell your data, show ads, or use third-party analytics. We disclose data only if the law requires it.

Your choices

You can revoke API keys and close workspaces yourself at any time. To see, correct or delete the data we hold about you, or to delete your account, contact us below. Deleting an account revokes its keys and closes its sandboxes; activity entries expire on their own within 90 days, or sooner on request.
