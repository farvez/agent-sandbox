Quickstart

Replace <your key> with a key from API keys.

Python

pip install airlock-sandbox

from airlock_sandbox import Sandbox

with Sandbox(base_url="{{ base_url }}", api_key="<your key>", egress=["pypi"]) as sbx:
    sbx.run("pip install requests", timeout=60).check()
    print(sbx.run("python3 -c 'import requests; print(requests.__version__)'").stdout)

Claude Code

claude mcp add --transport http --scope user airlock "{{ base_url }}/mcp?egress=pypi" --header "X-API-Key: <your key>"

Connects over HTTPS, nothing to install. Add &workspace=name to the URL for a separate sandbox.

curl

curl -X POST {{ base_url }}/v1/sessions -H "X-API-Key: <your key>" -H "Content-Type: application/json" -d "{}"
